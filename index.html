Canvas Training: Course Content Import Methods

Branching Exercise: The "Prior Semester" Choice — Copying a course from a previous term.

Step 1: Settings > Import Course Content

You are in your new course shell. You navigate to Settings > Import Course Content and select "Copy a Canvas Course" from the Content Type menu.

Decision Point: Canvas prompts you to choose which content to include. Select an option below to test the outcome:

➤ Choice A1: Select "All Content" and run the import ➤ Choice A2: Select "Select Specific Content" and run the import

[Outcome: High Friction & Disorganization]

Result of Choice A1 (All Content)

The Consequences

  • The Mess: Expired announcements from previous years publish to the course immediately.
  • The Chaos: Obsolete calendar events and legacy due dates populate the student syllabus and calendar views.

Simulated Student Feedback

"Hi Professor, I was trying to check the Week 1 quiz, but Canvas states it has been locked since two years ago. Is this course ready for us?"

The Technical Fix:

  1. Pre-Import: Under Import Course Content, check "Adjust events and due dates" to shift dates to the new term or remove dates entirely.
  2. Post-Import: Go to the Assignments index > click the Options menu (3 dots) > select "Edit Assignment Dates" to bulk-modify all deadlines in a single table.
↩ Return to Decision Point

[Outcome: Recommended Best Practice]

Result of Choice A2 (Select Specific Content)

The Consequences

  • The Win: A "Select Content" button appears in the Current Jobs queue. You can selectively check only your Modules and Question Banks, avoiding legacy Announcements and outdated settings.
  • The Feedback: The course development shell remains clean, modular, and organized with zero clutter.

The Reward: Level Up to Batch Date Editing

With a clean structure in place, navigate to Assignments > Options (three vertical dots) > Edit Assignment Dates to align the new due dates with the current semester syllabus.

↩ Return to Decision Point
